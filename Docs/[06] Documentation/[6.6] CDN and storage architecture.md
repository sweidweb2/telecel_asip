## Architecture (today)

| Layer | Source of truth | Caching |
|--------|-----------------|--------|
| Marketing HTML / RSC | Next host (+ edge if deployed) | `Cache-Control: public, s-maxage=300, stale-while-revalidate=86400` via `next.config.ts` (Option A chrome) |
| Auth / dashboard HTML | Next host | `private, no-store` |
| Next static (`/_next/static/*`) | Build-hashed assets | Long-cache via Next/host defaults |
| Root static (ico/png/OG) | `app/` / rare `public/` files | `public, max-age=31536000, immutable` via `headers()` |
| Media | Supabase Storage public buckets + Supabase edge | Versioned object paths + `cacheControl: "31536000"` + WebP pipeline |
| Partner logos | Third-party `cdn.21st.dev` | External |
| App data cache | `unstable_cache` + tags in `data/` | `revalidateTag` / `revalidatePath` in `actions/` |

**No custom first-party CDN** (`cdn.…` domain, `NEXT_PUBLIC_CDN_URL`, purge API). Media URLs are:

`{NEXT_PUBLIC_SUPABASE_URL}/storage/v1/object/public/{bucket}/{path}`

## HTTP cache-control split

Configured in [`next.config.ts`](../../next.config.ts) `headers()`:

| Surface | Cache-Control | Notes |
|---------|---------------|--------|
| Marketing `/en`, `/fr`, and public slugs (`about`, `portfolio`, `insights/…`, etc.) | `public, s-maxage=300, stale-while-revalidate=86400` | Auth-agnostic HTML (Option A). Locale is in the URL. |
| `/dashboard/**`, `/login`, `/signup`, `/register`, locale auth pages | `private, no-store` | Never shared-cache |
| Root static `*.svg|ico|png|…`, `/opengraph-image` | `public, max-age=31536000, immutable` | Prefer hashed `/_next/static` for app assets |
| Supabase Storage objects | Object `cacheControl: "31536000"` on upload | Immutable nanoid `.webp` paths |
| Next data cache (not HTTP) | `unstable_cache` ~300s + tags | Blogs / startups reads |

**Middleware (CDN-friendly):**

- Session refresh only on dashboard + auth routes.
- Locale cookie (`LOCALE_COOKIE`) is **Set-Cookie only when the value changes** — avoids blocking shared HTML caches on every marketing hit.
- Path locale (`/en/…`, `/fr/…`) is the source of truth for content.

APIs / Server Actions inherit dynamic/private behavior; do not mark them public at the edge.

## One-time reviews (completed)

### 1. Blog `cacheControl` — fixed

- `actions/blogs.ts` sets `MEDIA_CACHE_CONTROL = "31536000"` on cover/avatar uploads (aligned with startups `LOGO_CACHE_CONTROL`).
- `scripts/seed-blogs.mjs` also uploads with `cacheControl: "31536000"`.

### 1b. Upload image pipeline — fixed

- Shared helper: `lib/media/process-image.ts` (Sharp → rotate, max-width resize without upscale, WebP quality 80).
- Presets: `blogCover` 1600px, `blogAvatar` 512px, `startupLogo` 512px.
- Wired in `actions/blogs.ts`, `actions/startups.ts`, and mirrored in `scripts/seed-blogs.mjs`.
- Stored objects are always `.webp` / `image/webp`. Animated GIF input becomes a static WebP.
- AVIF / multi-variant sizes remain future work.

### 2. Storage buckets

| Bucket | Public | Limits | Write | Notes |
|--------|--------|--------|-------|--------|
| `blogs` | Yes | 5MB; jpeg/png/webp/gif | Admin only | Covers / thumbnails |
| `auther` | Yes | 2MB; same MIME | Admin only | Author avatars (name typo kept for ops stability) |
| `startups` | Yes | 5MB; same MIME | Admin only | Logos only today |

- Pattern: public SELECT; admin INSERT/UPDATE/DELETE via `public.is_admin()`.
- App always builds **public** object URLs for these buckets.
- **No private buckets** yet (acceptable while all media is public marketing content).

### 3. `remotePatterns` (`next.config.ts`)

Pinned allowlist:

- `www.untitledui.com`
- `cdn.21st.dev`
- Supabase hostname from `NEXT_PUBLIC_SUPABASE_URL` with pathname `/storage/v1/object/public/**` only (no `*.supabase.co` wildcard)

### 4. Image components

| Surface | Optimizer |
|---------|-----------|
| Blog cards / featured / insight detail covers | `next/image` |
| Startup cards / detail / admin logos | `next/image` |
| Logo cloud | `next/image` |
| Author avatars (blog / featured / insight) | `AuthorAvatar` → `next/image` |
| Editor local File previews | plain `<img>` (correct for `blob:`) |

### 5. HTML caching — Option A + marketing `s-maxage`

**Rendering:** Marketing HTML is **auth-agnostic** (always Apply; Login in footer; no `isAuthenticated()` in marketing chrome).

**HTTP:** Marketing routes send shared-edge-friendly `Cache-Control` (see table above). Auth/dashboard stay `private, no-store`.

**What we also cache:**

- Content reads via Next data cache (`unstable_cache` + tags, e.g. `BLOGS_CACHE_TAG`, `STARTUPS_CACHE_TAG`, ~300s revalidate).
- Mutations invalidate with `revalidateTag` + relevant `revalidatePath`.
- Media: new object key + long Storage TTL.

Do **not** reintroduce auth-dependent marketing chrome or client session peeks on marketing without revisiting this decision.

### 6. Invalidation model (no CDN purge)

| What changed | How we invalidate |
|--------------|-------------------|
| Blog / startup DB rows | `revalidateTag` + path revalidation |
| Replaced media file | New versioned path in DB; delete old object; old URL ages out via TTL if still linked |
| Marketing HTML at the edge | Short `s-maxage` (300) + SWR; tag/path revalidate refreshes origin |
| Custom CDN object purge | **Not used** — do not add until a custom CDN requires it |

### 7. `public/` static files

Unused default Next SVGs (`file.svg`, `window.svg`, `vercel.svg`) removed. Any future root static files get long-cache `headers()`; prefer `/_next/static` hashed assets for app UI.
