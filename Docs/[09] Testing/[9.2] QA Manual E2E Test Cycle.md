# [9.2] QA Manual E2E Test Cycle

**Audience:** QA team  
**Purpose:** Full manual end-to-end regression cycle for the ASIP platform (marketing site, auth, intake forms, Editor CMS, Admin ops).  
**Scope source:** Application routes, Server Actions, validations, middleware, and site settings as implemented in the product.  
**Not in scope:** Automated Vitest / Playwright suites (engineers run those separately).

---

## How to run this cycle

1. Use a **staging** (or local) environment linked to a **non-production** Supabase project whenever possible.
2. Complete sections in order when doing a full release cycle. For hotfixes, run **§0 Smoke**, the touched feature section, and **§18 Sign-off**.
3. Mark every row: `[ ]` not run · `[x]` pass · `[F]` fail · `[N/A]` not applicable.
4. Log failures with: **URL**, **role**, **locale**, **steps**, **expected**, **actual**, **screenshot / video**, **severity**.
5. Retest failed items after fix; do not close the cycle until blockers are resolved or explicitly waived.

### Breakpoints to spot-check

| Viewport | Width |
| --- | ---: |
| Mobile | ~375px |
| Tablet | ~768px |
| Desktop | ~1280px |

Every UI section must pass at least once on mobile and desktop. Prefer real devices for intake forms and staff shells.

### Recommended test accounts

| Role | Shell after login | Notes |
| --- | --- | --- |
| **Admin** | `/admin` | Ops: users, settings toggle, performance, backup. Cannot write CMS content (editor RLS). |
| **Editor** | `/dashboard` | Full CMS + limited user management. |
| **Viewer** | `/{locale}` marketing home | Public only; staff shells blocked. |
| **Unsigned** | — | Marketing + public forms; intake redirects to login. |

Keep one extra **viewer** and one **editor** for delete / last-role protection tests. Never use production founder PII in test submissions.

### Environment checklist (before cycle)

- [ ] Correct base URL confirmed (staging vs local)
- [ ] Supabase project is the intended remote (or local stack)
- [ ] At least one admin + one editor + one viewer account exist
- [ ] Test image assets ready: JPEG, PNG, WebP, GIF, oversize (>5 MB and >2 MB), non-image (PDF/TXT)
- [ ] Browser: Chromium + one of Firefox / Safari / Edge
- [ ] Clear cookies / use private window when switching roles
